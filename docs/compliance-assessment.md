# 节点来源合规评估 — VPN.lat (hetecn.com)

按 vpn-app-reverse SOP 第 3 步执行。

## 判定

| 项 | 结论 |
|----|------|
| 节点归属 | hetecn.com / VPN.lat 厂商自租（IP 段含 OVH 54.39.x、Hetzner、107.152.47.115 等） |
| 授权状态 | 付费用户凭证，未授权第三方直连 |
| 凭证性质 | 硬编码应用级 token（非用户级），无账号绑定 |
| Geo-Gate | 84 国白名单 + ASN 过滤，说明厂商有明确分发意图边界 |

## 结论: ❌ 不可入生产代理池

与 Gulf Secure VPN / Privify / ZeroPing 判例一致：逆向披露凭证是研究，把厂商付费服务器挂进生产池是盗用基础设施。

## 可入池替代

- VPNGate（公共志愿源，SOP 已有测活代码）
- 免费代理源聚合（new-api 已有 31 源管线）
- 自租 VPS 自建

## 允许的使用

- 协议研究与披露（本仓库）
- demo 服务（本地，不对外提供节点流量）
- 与厂商联系获取授权后的正式接入
